# GET routes are reachable by the viewer and bot roles unless
# _api_route_allowed / _api_bot_allowed deny them: a new route ships as a
# viewer route by default. The tripwire in api-docs.sh fails CI when a
# sensitive-looking path (env, secrets, files, export, terminal, backups,
# dns, recovery, tokens, sessions, webhooks, auth, config, settings, logs,
# history, metrics, ...) is reachable without admin rights, or when a
# public non-GET route exists.
#
# Lines below are the recorded decision: "METHOD /pattern", one per line.
# To keep a new route off this file, deny it in the policy functions in
# .scripts/api-server.sh instead. To keep it viewer-readable on purpose,
# add its line here — the diff makes the choice reviewable.
# =============================================================================
